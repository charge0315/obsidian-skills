# note.com投稿変換スキル

Obsidian Flavored Markdownのノートを、note(note.com)のWebエディタに貼り付けて破綻なく反映できるプレーンなMarkdownに変換する。

## 前提: note.comエディタの制約

- note.comはWYSIWYGのブロックエディタで、Markdownファイルを直接インポートする公式機能は無い。貼り付け時にテキストを解析し、一部の記法を自動でブロックに変換する。
- 貼り付け時の自動変換は完全に安定しているわけではない。見出し・太字・箇条書き・引用・区切り線程度に記法を絞り、記事全体を一度にプレーンテキストとして貼り付けるのが最も安定する。
- 画像はMarkdownの `![](url)` 記法では反映されない。エディタ上のアップロードUIから個別に追加する必要がある。
- テーブル、LaTeX数式、Mermaid図はnote.comのエディタが対応していない。
- noteには非公式API(`text_notes`系エンドポイントなど)が存在するが、Cookieセッションの詐取や利用規約違反のリスクがあるため本スキルでは扱わない。投稿は必ず公式Webエディタへの手動貼り付け・手動アップロードで行う。

## ワークフロー

1. 変換対象の `.md` ファイルを読む。
2. 下記の変換表に従ってObsidian固有記法を除去・変換する。
3. 画像・添付ファイルはプレースホルダに置き換え、アップロード用チェックリストとして別途書き出す。
4. 変換後のMarkdownを別ファイル(例: `<元のファイル名>.note.md`)として保存する。
5. note.comの下書きエディタに全文を貼り付け、見出し・太字・箇条書き・引用が意図通り反映されているか確認する。
6. チェックリストに従って画像アップロード・ハッシュタグ入力など手動作業を行う。

## 変換表

| Obsidian記法 | note.com向けの処理 |
|---|---|
| frontmatter (`---`〜`---`) | 削除。`title` があれば先頭に `#` 見出しとして復元する |
| `[[Note]]` wikilink | 表示テキストのみのプレーンテキストに変換(リンクは失われる) |
| `[[Note\|表示]]` wikilink | `表示` 部分のみ残す |
| `[[Note#Heading]]` | 見出し部分を含めた表示テキストに変換、またはプレーンテキスト化 |
| `![[image.png]]` 画像embed | `[要手動アップロード: image.png]` のようなプレースホルダに置換し、アップロードチェックリストに追記 |
| `![[Note]]` ノートembed | 埋め込み先の内容を展開するか、`[[Note]]` と同様にプレーンテキストのリンク表記に変換 |
| `> [!type] タイトル` callout | 通常の引用(`>`)に変換し、タイトルは1行目に太字で残す(note.comはコールアウト非対応) |
| `==highlight==` | `**強調**`(太字)に変換。note.comにハイライト記法は無い |
| `#tag` `#nested/tag` | 本文中からは削除し、記事末尾にプレーンテキストの一覧として残す(note.comはハッシュタグを本文と別のUIで入力する) |
| `%%comment%%` | 削除 |
| `^block-id` | 削除 |
| 脚注 `[^1]` / `[^1]: ...` | note.comは脚注リンクに非対応。本文中に注記として展開するか削除する |
| LaTeX `$...$` / `$$...$$` | note.comは数式非対応。削除するか、数式であることが分かるプレーンテキストに置き換えて警告を残す |
| Mermaid図 | note.comは図表非対応。削除し、必要なら別途画像化してから手動添付する旨を警告として残す |
| コールアウトの折りたたみ (`-`/`+`) | 通常の引用として展開する(折りたたみ非対応) |
| テーブル | note.comはテーブル非対応。箇条書きへの変換を提案するか、対応不可として警告を残す |
| タスクリスト `- [ ]` / `- [x]` | 通常の箇条書きに変換(チェック状態はテキストに残す: `[未完了]` / `[完了]`) |

## 出力後の手動チェックリスト

変換後のMarkdownと合わせて、以下を必ず提示する。

- アップロードが必要な画像・添付ファイルの一覧(元のファイルパス付き)
- 対応不可のため削除・簡略化した要素(テーブル、数式、図など)の一覧
- 記事末尾に列挙したハッシュタグ候補
- 内部リンク(wikilink)がプレーンテキスト化された箇所の一覧(必要ならnote.com側で手動リンク化)

## 参考: note.com側で有効なMarkdownショートカット

貼り付け後、note.comのエディタ自体が解釈できる記法。変換結果はこれらに絞ると安定する。

| 記法 | 結果 |
|---|---|
| `## ` | 見出し(大) |
| `### ` | 見出し(小) |
| `**text**` / `__text__` | 太字 |
| `> ` | 引用 |
| `---` | 区切り線 |
| `- ` | 箇条書き |
| `1. ` | 番号付きリスト |
